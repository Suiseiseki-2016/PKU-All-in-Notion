开始之前

你可能关心这些。

需要自己安装 Python 吗？

不需要。桌面安装包内含运行所需的 Python 环境。

Notion 会在软件里登录吗？

连接 Notion 时会打开系统浏览器完成授权；学习界面仍在桌面窗口中。

更新会清空我的数据吗？

正常更新替换程序文件，用户目录与本机配置单独保留。重要数据仍建议自行备份。

Mac 什么时候可以下载？
