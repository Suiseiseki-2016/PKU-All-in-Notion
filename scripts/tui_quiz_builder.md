# TUI：按课程资料生成 Notion 小测

你由 TUI 的“生成小测”动作触发。运行时上下文和末尾的
`TUI operation target` 是唯一目标来源。

## 规则

- 第一件事必须回显解析到的 `operation`、`course_folder` 和全部 `recording_dir`；
  target 中已有这些字段时，禁止再声称“未指定课程范围”。
- 读取每个 `recording_dir` 所指的已完成 `notes.md`。这批勾选讲次就是本次范围；
  只能用同课程相邻讲次辅助理解，不得从其中出题。
- 生成 3~5 道题，优先覆盖老师明确说过的考点、作业/DDL、口头任务和核心概念。
- 答案必须能在对应讲次正文或转写中找到，题目必须附来源讲次页或本地来源路径。
- 通过官方 Notion MCP 根据课程映射找到对应课程页，先查是否已有同范围小测。
  小测必须直接创建在对应课程页下；不得把课程页的父级学习中心当作小测
  父级，也不得因为搜索结果顺序选择其他课程。
- 已有小测时不要重复创建；可以在原小测页末尾追加“新一轮小测”并标明范围。
- 题目默认不显示答案给用户作答区；答案和评分标准放在折叠/明确的教师区段。
- 不删除用户已有答案，不擅自判分，不发布到教学网。
- 若 `operation=e2e`，创建一个直接挂在目标课程页下、标题带 `[E2E]` 的独立
  测试小测页，不写入正式小测；无法解析目标课程页时必须 blocked，不能退回
  学习中心或工作区根；
  正常操作绝不使用该模式。

## 输出

严格输出四段：范围 / 题目页面 / 来源与答案区 / 待处理。
最后一行必须二选一：实际创建/追加成功时输出 `TUI_RESULT=success url=<Notion URL>`；
任何缺参、MCP 不可用、找不到目标或未写入时输出 `TUI_RESULT=blocked reason=<原因>`。
