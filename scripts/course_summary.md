# 课程总结生成运行手册（考前快照）

> **手动触发**，考前 1~3 周跑一次。目标：把一门课**已有的全部讲次页**聚成一页《课程总结》快照——老师点名的考试重点置顶（带原话与出处）、主题要点归并、考核与 DDL 汇总、缺口清单。素材全部来自讲次页与数据库已有内容，**不新造知识点**。
>
> 姊妹手册：`lecture_notes_writer.md`（单讲整理，讲次页规范单一来源）、`daily_review_mcp.md`（每日对账 + 口头任务/自测错题联动）。结构基准：认知心理学手工总结页《认知心理学｜课程总结（截至 2026-09-13）》（定位 → 主题核心 → 考核 → 考试重点与待确认 → 资料依据），本手册把「老师点名的考试重点」提为置顶段。

## 0. 工具边界

- 必须有 `notion` 组 MCP 工具，否则回复 `NO_NOTION_TOOLS` 立即结束。
- Notion 只经官方 notion MCP 读写；**不删**页面/行/内容，**不整页覆盖**既有页（快照页只新建）。
- 不需要读本地课程数据；若要核对转写原话，可用 pku-sync MCP 只读。
- 课程页定位：优先查 `lecture_batch_creator.md` §1 的课程映射表；通用场景按 hub 子树搜索课程名动态定位。
- 触发时机：考核库该课出现 14 天内的已确认考试时，晨检会在「待处理」段提醒跑本手册（`daily_review_mcp.md` §5）。

## 1. 触发参数

```
course=认知心理学
exam=期中        # 期中 | 期末 | 随堂小测（进标题与考核段定位）
```

用户一句「给 X 课做课程总结」等同此参数块；`exam` 缺省时按考核库里该课最近一场已确认考试。

## 2. 收集素材（只读）

1. 定位课程页（§0），`notion-fetch` 拿全部子页。
2. 讲次页 = 标题匹配 `《第N讲 · …》` 的子页，**逐页 fetch 正文**，一页不落；缺讲（有课没页/转写未完）记入缺口。
3. 在 hub 子树定位「考核」「学习任务」数据库，先 fetch schema 再 query 该课行：
   - 考核：`exam` 对应行（日期/时段/确认状态/备注）；
   - 学习任务：该课全部状态非 Done 的行（DDL 汇总用）。
4. 课程页下若有旧《课程总结》快照或课件总结类子页 → fetch 并入素材（重点核对旧「待确认」是否已有答案，有则新快照里标「已解决」）。

## 3. 抽取规则（全部来自讲次页已有内容）

- **考点**：讲次页 §4.2 第一类加粗条目 + 老师原话（「」/引用原样搬）。
- **作业与考核**：§4.2 第二、三类加粗条目（截止/占比/平台/口头任务）。
- **主题要点**：各讲 `## 一、…` 大主题段的标题与主 bullet 结论；对比表格整表搬；子 bullet 的例子不搬。
- **待核**：`## 📌 需要自行核实的点` 条目；已被后续讲次/旧快照解决的标「已解决」。

## 4. 生成快照页（主写操作）

`notion-create-pages`，`parent.page_id = course_page_id`，icon 不设。

- 标题：`<课程>｜课程总结（<exam>·截至 YYYY-MM-DD）`，日期取当天。
- 幂等：课程页下已有**同名**标题 → 不再建，回复已有 URL；已有**更早日期**的同 exam 快照 → 照常新建（快照按日期累积，永不覆盖）。

正文六段，顺序固定：

1. `# 课程定位` — 3~6 条 bullet：这门课研究什么、主线进行到哪（编号列出）、与哪些学科交叉。来自第一讲开头段与各讲大主题。
2. `# 老师点名的考试重点` — **置顶核心段**。每条 = 考点 + 老师原话 + 出处 `《第N讲 · …》`链接；只收讲次页里加粗的考点条目，**不加自己的推断**；多讲重复的考点合并为一条并列全部出处。
3. `# 一、…` `# 二、…` — 主题归并段：按课程主题归并，**不**按讲次流水；要点保留讲次页原措辞与加粗；对比表格整表保留；段内条目附出处讲次链接。3~6 段为宜，超过就合并相近主题。
4. `# 课程考核与学习要求` — 考核库该课行 + 讲次页加粗的作业考核原话 + 学习任务库未 Done 行的 DDL 清单（任务名 + 截止日期）。
5. `# 待确认事项` — 仍未解决的待核条目（带出处）+ 考核库确认状态非「已确认」的行。
6. `# 资料依据` — 用到的全部讲次页（标题 + 链接 + 日期）+ 缺口清单（无讲次页/转写未完的讲次；对不出的写「未核对」）。

**兜底登记**（附带写操作）：全量扫描发现的、晨检近 7 天窗口漏掉未登记的口头任务，按 `daily_review_mcp.md` §3.1 的幂等键补进学习任务库（只新增行），并在第 4 段 DDL 清单里以补登后的行为准。

## 5. 汇报（中文四段）

**触发参数 / 生成结果**（URL、覆盖讲次 N/M）**/ 已落登记**（兜底补登的任务行）**/ 待办**（缺口清单 + 待确认项）。

## 6. 红线

- **不删不覆盖**：只新建快照页与新增数据库行；讲次页、旧快照、既有行一律不动。
- **考点不可压缩**：老师点名的考点逐条保留原话（与 `lecture_notes_writer.md` §4.2 同一条红线）；压缩只能作用于普通讲解内容。
- **不新造知识点**：只重组讲次页已有内容；讲次页没写的结论不进总结。
- **不猜**：缺的讲次列入缺口，不用记忆/外部资料补写。
- 每条考点、每条 DDL 带出处链接；给不出出处的内容删掉。
