# 作业提交运行手册（文本 / 附件作业）

作业中心和 `pku-sync submit text/file` 共用草稿、账号绑定、文件校验、跨设备提交许可和回执保存流程。正式目标必须唯一映射到教学网的 `course_id` 与 `content_id`。Notion 和本地目录只显示官方事实的投影。

适用范围是 Blackboard 正式作业的文本答案与单个附件（PDF、DOCX、ZIP 等）。教学网测试、讨论区、成绩和教师反馈使用其他入口。

## 预览和确认

1. 从教学网完整同步课程目录，核对正式作业要求与截止时间。
2. 导出已检查的答案文件，或准备完整文本。单个文件最多 20 MB。
3. 运行预览命令，软件会复制实际待提交内容到 `<data_dir>/submission-drafts/<draft_id>/`，保存 `draft.json` 清单。预览不登录教学网，不创建提交尝试，也不获取发送许可。

   ```powershell
   pku-sync submit text --course _101578_1 --content _1708913_1 --file answer.md
   pku-sync submit file --course _101578_1 --content _1708913_1 --file answer.pdf
   ```

4. 检查打印的课程、作业、原要求、截止时间、草稿目录、文件清单和 SHA256。文本方式会显示完整答案。打开草稿目录中的实际文件检查。
5. 用户明确决定提交后，在命令后加 `--yes`。该次运行会重新准备并显示草稿，仍需在提示中二次确认当前文件、目标和清单；`--yes` 不跳过确认。取消后保留草稿，可在作业中心继续查看。

逾期会显示警告，是否提交由用户确认。教学网失败或不完整的读取状态必须先由完整同步恢复，旧缓存不能授权提交。正式作业要求、账号或实际待上传内容变化时，软件会停止，要求重新准备。

## 共享许可与回执

账号服务按账号、教学网账号、课程、作业和草稿保存提交许可。服务不支持新协议或不可用时，软件停止，不回退到仅靠本机锁的方式。内容校验通过后，软件先持久化并回读待核验状态，再发教学网 POST。已进入发送阶段的请求不会自动过期或允许另一台设备重发。

HTTP 200、`destinationUrl` 或附件上传的空响应均只是临时结果。成功还要求重新读取同一课程、同一作业的教学网提交历史；登录跳转、其他作业、脚本文字和仍有提交表单的页面不能作为成功回执。完整教学网 HTML、摘要、目标和验证时间会自动保存到草稿 `draft.json`。账号服务只接收验证元数据，不接收教学网 HTML 或会话字段。

在作业中心的“本机教学网回执记录”可下载回执 JSON。保存的是当时的历史证据；当前提交状态仍需由“读取教学网提交状态”查询，不能由 Notion 任务状态或本地回执推断。提交历史也不证明教师已公布成绩。

## 中断与恢复

- 已读到完整回执、账号服务保存中断：在作业中心点击“恢复回执保存”。软件补齐原记录，不再登录教学网或发送作业。
- 原请求未进入发送阶段：点击“核对未完成记录”。只有服务端证明原操作仍未发送，且条件释放与回读成功，才结束旧草稿许可。之后可重新准备新草稿并确认。
- POST 超时、HTTP 500、文本响应异常或缺少可验证回执：保留待核验状态，先到教学网核对。不要重跑提交或改用另一台设备发送。
- 原服务记录缺失、旧协议、账号不符或回执损坏：保留现有文件并停止自动恢复。一般“提交历史”页面不能解除某份未知草稿的共享许可。
- 课程名匹配多门时，改用明确的教学网 `course_id`。
