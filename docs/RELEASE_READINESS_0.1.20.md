## 当前阻断

### 1. 真实笔记事实质量

独立审阅以同目录 `transcript.json` 为唯一课堂证据，发现以下仍需修订：

- 发展心理学 09-08：`今晚 8 点` 截止时间无转写依据；Watson “12 个婴儿”也无依据。
- 发展心理学 09-15：把学生点名误写成“小班助教名单”，并加入多个未被转写支持的遗传学数字和术语。
- 信息安全 09-10：殖民管道 `500 万美元比特币赎金`、卡内基梅隆/CERT 归因无转写支持。
- 计算机网络 09-09：AWS Snowmobile `100 PB` 无转写支持。
- 认知心理学两讲：外部知识改写课堂年代、人物和概念；其中一讲还存在答案自相矛盾和章节空缺。
- 心理咨询 09-14：把纳曲酮/双硫仑等临床机制写成课堂事实，但转写没有依据。
- 计算概论两讲：章节空缺、未标注的语言/运算符补写和静默纠错。
- CNS 解剖 09-09：未标注的髓纹分界、颈膨大节段等解剖细节，以及对 ASR 数字的错误复述。
- 发展心理学 09-08、信息安全 09-10：仍有较大比例的繁体中文正文泄漏，虽已声明 `zhconv` 依赖，旧笔记仍需重新生成。

可直接进入候选发布的样本只说明局部质量已达标，不能代表整批课程可发布。报告中的“publishable”仅针对对应讲次和已抽查内容。

### 2. 短片证据门禁

`pku_sync/panel/note_videos.py` 现将标记分为：

- 转写存在且佐证分数达到阈值：允许切片；
- 转写存在但分数不足：记录 `unverified`，保留文字标记，不上传错误片段；
- 转写不存在：记录 `unverified` 和 `verification_pending`，保留原录像，等待以后重试；
- 上传/切片失败或预算不足：保持 `partial`，不清理原录像。

这解决了已发现的 92:23 错标：该处实际是 Git 合并内容，作业截止时间在 95:13，错误片段不得发布。

### 3. 依赖锁和发布签名

- `uv.lock` 已检测到需要更新，但当前仍被运行中的 `pku-sync process` 映射占用，`uv lock` 返回 Windows os error 1224。必须在该进程自然结束后重新锁定并执行 `uv lock --check`。
- 0.1.20 NSIS 已生成，但没有更新私钥，不能生成可验证的 Tauri 更新签名。不要启用更新清单。
