# 试点使用指南（Pilot Guide）

本文面向**非开发者的试点学生**：以浏览器面板为主，逐步完成安装、激活、
连接 Notion、同步课程、浏览资料与练习、批改与恢复。文中命令都按
**打包后的成品**逐条实测过（本机可运行的条目验证记录见下文「附：命令
实测记录」；macOS / Linux 专属命令的整链路验收按
[`MACOS_LINUX_VALIDATION.md`](MACOS_LINUX_VALIDATION.md) 在真机执行），
照抄即可。

开发者和想深入了解内部机制的人请看 [`USER_GUIDE.md`](USER_GUIDE.md)
（开发者手册）与仓库根目录 [`README.md`](../README.md)。本指南只讲试点
需要知道的事。

> 试点原则（先记住这三条）
>
> 1. **面板优先**：日常使用全部在浏览器面板里完成；终端里的 TUI 工作台
>    （`pku-sync tui`）仍然随包提供，但属于**高级界面**，试点不要求使用。
> 2. **内容在 Notion**：客户端只显示讲次、资料、练习的**索引与状态**，
>    不保存也不展示正文、转写或答案。阅读、笔记、作答、看解析都在
>    Notion 页面里完成。
> 3. **凭据不落地**：教学网密码、平台兑换码、Notion 授权等都不会出现在
>    浏览器或本地文件里；面板只在本机回环地址（127.0.0.1）上运行。

## 1. 安装（按操作系统）

安装包/安装脚本会把以下三样装好：官方 `uv` 工具、uv 管理的 Python 3.11
（不需要系统预装 Python）、以及本应用本身（通过公开软件源按名字安装，
这样以后 `uv tool upgrade` 能直接更新到新版本）。

**个人数据不放在安装目录里**：激活凭证（`.env`）、数据与日志都保存在
用户的个人数据目录（Windows 为 `%USERPROFILE%\PKU-All-in-Notion`，
macOS/Linux 为 `~/PKU-All-in-Notion`），重装或升级不会碰到它们。

### 1.1 Windows

试点分发的是 Inno Setup 安装包，例如 `PKU-All-in-Notion-Setup-0.1.0.exe`：

1. 双击安装包。
2. 如果出现蓝色 **SmartScreen 提示**（「Windows 已保护你的电脑」），
   点击 **更多信息（More info）** → **仍要运行（Run anyway）**。
   这是**未签名安装包的正常提示**，试点阶段所有用户都会看到一次；
   安装包来自试点分发的渠道即为正常。
3. 安装过程会自动完成（安装 uv → 配置 Python → 通过公开软件源安装应用），
   用时取决于网络（中国大陆可选择镜像任务加速，见第 5 节）。
4. 安装完成后，用**开始菜单或桌面快捷方式「PKU All in Notion 面板」**
   启动：面板在本机启动，并自动打开浏览器。

等你拿到快捷方式后，手动模式的等价命令（供技术同学核对，日常不用手敲）：

```powershell
uv tool install --force --managed-python --python 3.11 --index https://pku.aeoluswu.info/packages/simple/ pku-course-sync
pku-sync panel
```

### 1.2 macOS

在「终端」里依次运行（每条一行，照抄）：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
# 安装完成后重新打开一个终端窗口（让 uv 进入 PATH）。uv 装在你的用户目录
# （~/.local/bin），不需要系统管理员权限。
uv python install 3.11
uv tool install --managed-python --python 3.11 --index https://pku.aeoluswu.info/packages/simple/ pku-course-sync
```

启动面板（先建好个人数据目录并进入，再启动；浏览器会自动打开）：

```bash
mkdir -p ~/PKU-All-in-Notion
cd ~/PKU-All-in-Notion
pku-sync panel
```

**macOS 的 iCloud 提示**：老版开发环境教程里有一条 macOS 专属故障——项目
虚拟环境放在 iCloud 同步的目录（桌面 / 文稿）时，iCloud 会给 `.venv` 加
`hidden` 标记，导致 Python 找不到包。**本安装方式不受影响**：应用以
`uv tool` 安装，运行环境位于用户目录下的 `~/.local/share/uv` 等**非 iCloud
同步目录**，不在「桌面与文稿同步」范围里，不存在上述故障模式。

### 1.3 Linux

与 macOS 相同的三条安装命令（`curl -LsSf https://astral.sh/uv/install.sh
| sh` + 新开终端 + `uv python install 3.11` + `uv tool install --managed-python
--python 3.11 --index https://pku.aeoluswu.info/packages/simple/
pku-course-sync`），启动面板的命令也一样：

```bash
mkdir -p ~/PKU-All-in-Notion
cd ~/PKU-All-in-Notion
pku-sync panel
```

> 说明：Windows / macOS / Linux 三端命令由同一套跨平台代码提供（产品
> 代码不含任何操作系统专属逻辑），上述命令在三端行为一致。

### 1.4 安装后自检

打开面板后，浏览器停在**面板首页**。地址栏应显示 `http://127.0.0.1:<端口>/`
（默认端口 8791；被占用时自动改用 8792 / 8793，面板启动时会打印实际端口）。
点击首页上的「**打开学生面板**」进入学生界面（地址为
`http://127.0.0.1:<端口>/app`）。

命令行自检（可选）：

```powershell
curl.exe -s http://127.0.0.1:8791/healthz
# 期望输出：{"ok":true}
```

```bash
pku-sync doctor
# 期望：全部通过（首次使用会有两条「还没跑过」类警告，属正常）
```

## 2. 激活与配额

1. 在学生面板的激活页（「连接完成，只差一步」）输入你的**兑换码**，
   点「**立即激活**」。
2. 成功后页面提示会变成类似 **「激活成功，剩余 N 分钟。」**；激活后
   配额卡显示两块：

   - **转写 N 分钟** —— 云端转写（录音转文字）的剩余额度；
   - **AI 点 N** —— 整理练习、批改答案等 AI 操作的余额。

3. **配额用尽（402）**：当 AI 点不足时，面板会显示固定的提示：
   `AI 点不足，请兑换新额度后重试。`（整理练习前若余额不足，提示
   `AI 点不足，至少需要保留 5 AI 点才能开始整理。`）；转写额度用尽后，
   云端转写会停止。

4. **去哪里拿新的兑换码**：兑换码**由课程助教或学校统一发放**（激活页
   原文：`兑换码由课程助教或学校统一发放；开通凭据只保存在学校服务端，
   不会出现在你的浏览器或设备中。`）。额度用尽 = 联系发放兑换码的人
   （试点运营者 / 课程助教）申请补充，不要找 Notion、不要找教学网。

> 试点期间请留意：云端转写按分钟计量、AI 操作按点计量；面板显示的余额
> 就是你的实际可用额度。

## 3. 连接 Notion 与同步

1. 激活后在激活页点击 Notion 一行的「**重新连接**」；浏览器会打开授权
   页，确认后放行（只读你的学习空间）。
2. 连接后状态显示 **「内容将同步至你的空间 · 已连接」**；此时进入课程
   列表会自动开始同步索引（顶部出现「正在同步索引」，完成后变为
   「同步完成」）。
3. 如果 Notion 连接断开，目录会显示专门的**已断开状态**并要求重新连接
   （面板不会拿旧索引冒充当前数据）。

**同步失败**时面板显示「同步遇到问题」+ 重新同步按钮，而**不会是**成功
或静默空白。失败原因见第 6 节支持边界。

## 4. 面板日常使用（面板优先）

学生界面 `http://127.0.0.1:<端口>/app` 的日常路径：

- **总览**：已索引讲次 / 已索引资料 / 上次同步，课程卡片与最近动态。
- **课程 → 讲次**：选择课程后查看讲次列表；每个讲次显示「N 份关联资料」
  或「资料映射待确认」。点「在 Notion 打开讲次页」/「在 Notion 写笔记」/
  「在 Notion 开始练习」都会用存好的页面身份打开对应 Notion 页面。
- **资料视图**：`按讲次` / `按资料类型` / `全部资料` 三种视图；右侧只展示
  索引信息与来源（课程资料索引 / 课堂录像笔记），**正文在 Notion 中查看**。
  尚未确认关联的资料带「待确认」标记，不会被误当成已关联本讲。
- **练习目录**：已整理 / 待作答 / 待批改 / 已批改 四种状态。在 Notion 里
  作答后回到面板点「**批改已提交答案**」；批改完成只显示分数小结、
  消耗的 AI 点和「**在 Notion 查看解析**」。

> 整条路径不暴露任何正文、转写、答案或本地路径；内容始终在 Notion。

## 5. 网络与安装加速（中国大陆可选）

- Windows 安装时可选「**使用 TUNA 镜像**」任务，依赖下载走国内镜像，
  实测可明显加快（应用包本身仍从公开软件源解析，镜像不影响应用本体）。
- `uv` 与 Python 解释器本身从 GitHub releases 下载，不经过 PyPI 镜像；
  若安装卡在两步之间，通常是网络问题，稍后重试即可。

## 6. 常见问题与恢复

### 6.1 端口被占用（面板打不开 / OAuth 授权总失败）

面板固定使用本机端口 **8791 → 8792 → 8793**，Notion 授权回调固定使用
**8765 → 8766**。三者都被别的程序占用时，面板会显示固定提示：

- 面板：`本地面板端口 8791、8792、8793 都被占用：关闭占用端口的应用后重试。`
- 授权回调：`本地回调端口 8765 与 8766 都被占用：关闭占用端口的应用后重试。`

恢复做法：找到并关闭占用这些端口的程序（常见：别的高校/网课类本地工具、
残留的后台进程），然后重新启动面板。**不要**试图修改端口——面板永远不会
使用清单之外的端口。

### 6.2 Notion 授权被拒绝 / 超时

- 如果你在授权页点了「拒绝」或授权未完成，面板显示 `授权被拒绝` 或
  `等待浏览器授权超时…` 一类提示：**重新点一次「重新连接 Notion」，在
  浏览器里完成授权即可**（授权码一次性有效，重试 = 重新走一遍授权）。
- 如果提示 `平台登录状态已失效：请重新激活后再登录 Notion。`，说明本地
  平台会话过期，回到第 2 节重新激活即可。

### 6.3 更新失败（版本升级卡住）

- 面板右上角显示 **Version 版本号**；有新版本时显示
  `new version N available`，点 **Apply on next start** 会在**下次启动时**
  执行 `uv tool upgrade pku-course-sync`。
- 如果升级没成功，面板显示 `Update deferred. The current version is still
  running; restart after retrying.`：**旧版本继续能用，你的数据（.env、
  课程索引、日志）不受影响**。等网络恢复后重新启动面板并重试即可。
- 手动升级命令（可选）：

```bash
uv tool upgrade pku-course-sync
```

  没有新版本时会输出 `Nothing to upgrade`，这是正常的。

### 6.4 配额耗尽（402）

见第 2 节：`AI 点不足，请兑换新额度后重试。`——联系发放兑换码的
课程助教 / 试点运营者申请补充，拿到新码后在面板重新兑换/激活即可。

### 6.5 其他异常先自检

```bash
pku-sync doctor
```

自检覆盖配置、凭据、依赖、宿主、日志、报告、磁盘七项；fail 项会给出
提示。自检输出请保留给支持人员。

## 7. 支持边界（遇到问题找谁）

| 问题 | 找谁 |
| --- | --- |
| 激活、兑换码、AI 点、转写额度、平台账号、云服务授权 | **平台运营者（试点：课程助教 / 运营者）**。兑换码由此处发放 |
| 教学网 / IAAA 登录、选课、课程可见性、成绩 | **北京大学相关职能部门（信息化 / 教务）**，教学网账号归学校管理 |
| Notion 页面打不开、工作区、权限、Notion 账号本身 | **Notion 官方**（help.notion.com / 客服），客户端只负责打开页面 |
| 安装包、更新、面板异常 | 试点反馈渠道（运营者；可附上第 6.5 节的自检输出与
  `%USERPROFILE%\PKU-All-in-Notion\panel.log` 或 `~/PKU-All-in-Notion/panel.log`）|

## 8. 单实例使用（重要）

**同一时间只启动一个面板实例。** 两个实例同时运行时会占用不同端口
（8791 / 8792 / 8793），但数据目录和任务调度（整理、批改这类单飞任务）
**只在单一进程内是安全的**——开两个实例容易互相干扰。

- 关闭面板 = 关闭窗口 / 按 `Ctrl+C` 停止终端里的面板。
- 再次使用前先确认上一个实例已退出（任务栏或进程列表里没有残留的
  `pku-sync panel`）。
- 冷启动后觉得「端口被占了」时，先按第 6.1 节检查是否是自己上次残留的
  实例还在运行。

## 9. TUI 工作台（高级界面，可选）

面板是本试点的日常界面；随包附带的 **TUI 工作台**（`pku-sync tui` 或
`pkutui`）属于高级界面：它**需要真实终端**（Windows 的开始菜单终端 /
终端 App，macOS 的「终端」，或 Linux 的终端模拟器），按 `Enter` 查看
课程详情、`Space` 勾选录音、`a/o/z/g` 触发 AI 操作、`q` 退出。不了解
它不影响试点使用；完整按键见 [`USER_GUIDE.md`](USER_GUIDE.md)。
