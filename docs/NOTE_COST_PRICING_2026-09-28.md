# 笔记生成成本与公开定价测算（2026-09-28）

本文以人民币计算。**观测值来自 2026-09-24 至 09-28 的 server-a 聚合计量；它是开发、验收和重跑混合样本，不能代表单名学生的正常月度用量，也不是阿里云账单。** 下方长期成本均按公开原价测算，不把限时免费额度计入可持续定价。

## 计价依据

- 语音识别：当前服务端模型 `qwen-audio-3.0-asr-flash-filetrans`，阿里云华北 2（北京）原价 **¥0.00022/音频秒**。新加坡价不同；本表只使用北京价格。[阿里云百炼价格](https://help.aliyun.com/zh/model-studio/model-pricing)

### 一节真实课程的单独观测

2026-09-22 发展心理学录像约 7,184 秒。2026-09-28 的章节笔记重跑在服务端记录到 **31 笔成功 AI 调用**，输入 77,053 token、输出 16,095 token，内部扣 491 millipoints（0.491 点，约 ¥0.0491 等值）。按上述公开 token 原价连续计算约 **¥0.04760**。这 31 笔是同一节课的来源页匹配、章节生成和事实审校；客户端两次在 600 秒到时后复用任务键取回已完成结果，没有对用户重复扣点。服务端没有该课程的专用成本标签，因此这是与本次独占测试时间窗吻合的聚合归因，而非供应商逐单账单。

录像识别在本次重跑之前已经完成，**本次没有重新产生 ASR 费用**。若按完整新课首次识别，7,184 秒 × ¥0.00022/秒 = **¥1.58048**，加这次 AI 调用约 **¥1.63/课**。这只是模型和 AI 的变动成本；本轮端到端约 25 分钟且笔记仍未通过人工质量验收，不能把低成本当作可发布价值或可承诺的处理速度。两次长等待推动了连接超时优化，后续需另测速度分布。

## 单节课及月度模型

基准假设：每 2 小时录像完整识别一次；章节整理、核对及合成共消耗 **100,000 输入 token + 30,000 输出 token**，且各次请求保持在上述 128K 输入档位。后两项是预算假设，**尚无按课程归因的生产数据**，应随公开试用数据替换。

计算式：`2 小时 ASR = 7,200 × 0.00022 = ¥1.584`；`LLM = (100,000 × 0.20 + 30,000 × 2.00) / 1,000,000 = ¥0.080`；合计 **¥1.664/两小时课**，即约 **¥0.832/小时**。ASR 占此模型变动成本约 95.2%。

### 22 学分、每周 22 小时的目标成本

用户指定的典型负载为**每周 22 小时全量新音频**。按 `52 周 ÷ 12 月`，不是简单乘 4：每月约 **95.33 小时 = 343,200 秒**，约 47.67 节两小时课。成本目标为每名活跃学生每月 **¥50 理想、¥100 可放宽；若笔记质量有明显提升，可到约 ¥150**。这些都是产品成本边界，不是订阅售价或目标毛利。连续使用四周仅 88 小时会低估约 7.7%；寒暑假、补课及跨月峰值应另按实际活跃月统计。

在上文**每两小时 100,000 输入 + 30,000 输出 token** 的预算假设下，Flash 每月约 ¥3.81；若全部同等 token 用当前 `qwen3.5-plus` 北京 ≤128K 基础档，则约 ¥10.68。Plus 相对 Flash 每月增加约 **¥6.86**，但这是按同样 token 数的反事实模型；实际 Plus 输出更长、思考 token 更多或重审次数不同，费用和时延都会变。Flash/Plus 官方单价分别见[Flash](https://help.aliyun.com/zh/model-studio/qwen3-5-flash)及[Plus](https://help.aliyun.com/zh/model-studio/qwen3-5-plus)。

表中 `+10%`、`+20%` 是把 **ASR 和 LLM 都按同一比例增加可计费用量** 的保守压力情景，不是观测到的失败率；仅重整笔记且复用转写时只增加 LLM，重复上传同一缓存录像也不应重复识别。服务失败是否计费应以请求日志和供应商账单核实。上述均是 API **边际变动成本**，不含固定服务器、数据库、OSS 临时音频与流量、备份、分发、运维、支付税费及人工质量复核。

若暂以**每名活跃学生每月 ¥20 的非模型成本分摊**作敏感性假设（不是实测账单）：3.1 单段率 + Flash 在 0% / 10% / 20% 重做时分别约 **¥31.08 / ¥32.19 / ¥33.30**；改为全程 Plus 是 **¥37.95 / ¥39.74 / ¥41.54**，可落在 ¥50 内。即使 3.1 token/小时上升至该单段的 2 倍、全程 Plus、20% 重做，也约 **¥50.26**，刚超过理想线；3 倍 + Flash 为 **¥50.75**。这说明 ¥50 模型对音频 token 分布、分摊成本与质量重做很敏感。相反，当前 3.0 + Flash 在 10% 重做、仅 ¥10 非模型分摊时约 **¥97.25**，勉强满足 ¥100；20% 重做即使不计分摊也占 ¥95.18，最多仅余 ¥4.82。若人工复核每节课都不可避免，这些假设分摊可能远低于实际成本。

将 ¥50 作为上线运营目标时，先量出服务器、OSS/出口和人工等非模型分摊，再定可承受的模型预算：例如假设非模型分摊 ¥20、20% 可计费重做，API 原始预算至多 `(50−20)÷1.2 = ¥25/月`。按本次 3.1 样本率，ASR 占 ¥7.27，留给笔记 LLM 及更高级模型约 **¥17.73/月**；比 Flash 基线 ¥3.81 多 **¥13.92/月**，足够容纳上述同 token Plus 额外 ¥6.86，但**不代表 Plus 已证明笔记质量提升**。若 3.1 音频 token 率升为 2 倍，LLM 原始预算缩到 ¥10.46/月，全程 Plus 的 ¥10.68 已略超。¥100、¥150 的相同计算分别为 API 原始预算 **¥66.67、¥108.33/月**；提高成本上限仍须以真实笔记质量收益和未量出的人工、共享基础设施账单为依据。

若未来的多课听音验收支持以 3.1 为主、只把低置信片段交给 3.0 复识，在同样 ¥20 非模型分摊与 20% 可计费重做假设下，还须控制复识比例。按本次 3.1 样本率、每段 **额外**支付 3.0 费用且不抵扣首次 3.1，`(7.27 + 3.81 + 75.50×复识音频比例)×1.2 + 20 ≤ 50` 给出 Flash 方案复识比例最多约 **18.4%**；若全程 Plus，最多约 **9.3%**。这是成本上限的算术推导，不是建议现在切换识别器；真实分段复识的音质和知识点收益、供应商账单及调用次数仍未测。

9 月 28 日的[高级模型单段试验](ADVANCED_MODEL_G02_2026-09-28.md)在已获授权的 G02 片段上调用一次 `qwen3.7-plus`：输入 1,843、输出 1,067 token，按北京公开价约 **¥0.0122**，但六条候选仅一条通过旧机械检查，且该句实读仍不自然。按同一套每两小时 100,000 输入、30,000 输出 token 假设，若全量改用此模型，LLM 约 **¥20.97/人月**；连同当前 ASR 3.0，API 约 **¥96.47/人月**，尚未计重做和非模型成本。这在质量确有提升时可能落入用户允许的约 ¥150 上限，但本次试验**没有证明质量提升**，不能据此切换默认模型或确定售价。

固定资源须按**同月实际活跃用户数**分摊，而不是按注册用户数。公式为 `人均固定资源 = 三台服务器、数据库、备份、监控、基础带宽等月账单合计 ÷ 当月实际活跃用户`。例如纯粹假设共享资源总账单为 ¥3,000/月，则 100 / 300 / 1,000 名活跃学生分别分摊 ¥30 / ¥10 / ¥3；若采用表中“3.1 样本率 + Plus +20%”的 API ¥21.54，相应合计已达 ¥51.54 / ¥31.54 / ¥24.54，**仍未含单用户 OSS、额外出口和人工**。因此低用户量下即使便宜的 ASR 也未必能守住 ¥50。

音频体积同样需要测：95.33 小时若压成平均 64/128 kbit/s，原始文件量约 **2.75/5.49 GB/学生月**（十进制 GB，`343,200 秒 × 比特率 ÷ 8`）。若临时 OSS 只留 1 天，储存 GB·月较小；若为缓存和追溯保留多个月，则容量按保留期累计。上传、百炼读取、跨地域出口、Notion 附件与下载的计费方向不同，不能只拿文件量乘一个虚构的流量单价。应从实际 OSS 与主机账单分别取存储 GB·月、请求次数、出网 GB、地域，再按活跃用户分摊；一节课的多次重整若命中缓存，应避免重复上传和识别。

### 敏感性与收费设计

- 若一节 2 小时课只用 25,000 输入 + 5,000 输出 token，LLM 为 ¥0.015；若用 200,000 输入 + 60,000 输出 token，且每次请求仍在 128K 档位，LLM 为 ¥0.160。该范围内 ASR 仍是成本主体。
- 若所有可计费调用增加 20%（例如重试和质量重跑），20 小时/月的基准变动成本从 ¥16.64 增至 **¥19.97**，70% 目标毛利对应最低售价 **¥66.56**；这是假设情景，不是已观察失败率。
- 套餐应按**每月可新识别的音频小时数**设清晰额度，缓存命中的同一录像不要重复扣完整识别额度；额外音频可按小时计费。笔记重整若复用已存转写，只产生 LLM 成本，应单独记录，避免用户为了改笔记重新支付识别成本。
- 不宜把当前内部“100 点”直接解释为市场售价。内部扣点规则、赠送额度与人民币供应商成本属于不同量纲。

## 发布定价前仍需补齐的实数

1. 从服务端按匿名用户、课程、成功/失败、缓存命中统计 ASR 秒数与 LLM token，连续观察至少一个完整学生月；排除开发账户和验收重跑。
