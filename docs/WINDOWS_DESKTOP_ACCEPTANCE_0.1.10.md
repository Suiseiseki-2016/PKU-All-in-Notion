# Windows 桌面版 0.1.10：教学网认证与录像下载验收

日期：2026-09-26。构建机：Windows 11 专业版 x64，10.0.26200。

## 故障与原因

0.1.9 完整整理一节课曾成功下载录像，但对同一录像再次执行“仅下载”时，界面约 7 分钟没有进度。它实际卡在重新登录教学网，尚未开始文件传输。排查发现进程环境的 `HTTPS_PROXY` 指向已停用的 `127.0.0.1:7890`，Windows 当前用户代理是可用的 `127.0.0.1:7897`；客户端自定义 `httpx.HTTPTransport` 提供重试，却绕过了自动代理配置。公开 IAAA 公钥接口直连在 5 秒内超时，经当前代理 0.06 秒返回 200。这是当前机器的路由与客户端代理选择共同导致的问题，不能据此认定北大认证服务整体故障。

修复：Windows Tauri 壳读取当前启用的用户 HTTPS 代理，传给 sidecar；Python 客户端只给 IAAA 身份认证挂载可用代理，录像媒体仍直接连接教学网源站。桌面界面在取录像前明确显示“正在连接教学网”。更新器也显式使用 Windows 用户代理。
